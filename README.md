# Slope-Calc

## How do I use it?
Go to dist/uri.txt, copy and paste the content of the file into the address bar.
Once there, input your x an ys value into the table and press "Calculate" to figure out the slope and y intercept of your values. (Make sure it's not undefined)

## How does it work?
It works by using html's table, you input the value, then it sends the data to the script (javascript) to solve the equation and checks if it's invalid or valid

## Building
```
npm install
node build.mjs
```
